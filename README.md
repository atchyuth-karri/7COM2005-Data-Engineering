# Data Engineering Team Project

### University of Hertfordshire | Module: 7COM2005

## About the Project

This repository contains the collaborative work for the Data Engineering Team Project as part of the 7COM2005 module at the University of Hertfordshire.

The project focuses on exploring and applying modern data engineering principles, technologies, and methodologies to develop a solution addressing a real-world data-related problem.

## Project Objectives

- Understand and apply modern data engineering principles.
- Explore data collection, processing, and storage techniques.
- Investigate suitable data engineering technologies.
- Develop a structured and scalable data engineering solution.
- Implement effective data management practices.
- Collaborate using Git and GitHub.
- Document the development process and findings.
